1. 任务背景与目标
当前问题：现有界面功能完整，但视觉风格偏基础（类似早期 Bootstrap 风格），缺乏现代 AI 产品的精致感与交互体验。具体表现为：侧边栏与主区域边界生硬、聊天卡片样式单调、缺少微交互与响应式适配。

改造目标：

视觉现代化：采用现代 AI 产品（如 ChatGPT、Claude、Perplexity）的设计语言，强调留白、层级、圆角和柔和阴影。

交互升级：引入平滑过渡动画、流式打字光标、悬停反馈和骨架屏。

响应式布局：支持桌面端（侧边栏固定 + 主区域自适应）与移动端（侧边栏抽屉式折叠）。

组件标准化：基于 Tailwind CSS 和 Shadcn UI 构建可复用的 UI 组件。

2. 技术栈与依赖

设计令牌（Design Tokens）：

主色：indigo-600（DeepSeek 品牌蓝）或 orange-500（与现有 Logo 呼应）

背景：bg-slate-50（主区域）、bg-slate-900（侧边栏）

文字：text-slate-800（主）、text-slate-500（辅助）

圆角：rounded-xl（卡片）、rounded-2xl（消息气泡）

阴影：shadow-sm（卡片）、shadow-lg（悬浮元素）

3. 布局重构

采用 左右分栏 + 主区域居中 的经典 AI 聊天布局：

AI 实现指令：

使用 flex h-screen 作为根容器，禁止页面整体滚动。

侧边栏固定宽度 w-80，使用 overflow-y-auto 独立滚动。

主区域 flex-1 flex flex-col，聊天记录区 flex-1 overflow-y-auto，输入框区 sticky bottom-0。

3.2 响应式适配
桌面端（≥1024px）：侧边栏常驻显示。

移动端（<1024px）：侧边栏默认隐藏，顶部增加汉堡菜单按钮，点击后以抽屉（Drawer）形式从左侧滑出，带半透明遮罩层。

4. 侧边栏改造
4.1 视觉风格
背景：bg-slate-900 text-slate-100，与主区域形成对比。

顶部 Logo 区：保留“星澜”品牌，图标使用渐变背景（bg-gradient-to-br from-orange-400 to-orange-600），文字使用 text-lg font-semibold tracking-wide。

分区标题：text-xs font-medium text-slate-400 uppercase tracking-wider，如“API 设置”、“知识库”。

4.2 API Key 卡片
用 bg-slate-800 rounded-xl p-4 包裹整个配置区。

输入框：bg-slate-700 border-slate-600 rounded-lg focus:ring-2 focus:ring-orange-500。

保存按钮：bg-orange-500 hover:bg-orange-600 transition-colors rounded-lg。

状态徽章：已设置时显示绿色圆点 + “已设置”，未设置时显示灰色圆点 + “未设置”。

4.3 知识库管理卡片
文件上传区改为虚线边框拖拽区：border-2 border-dashed border-slate-600 rounded-xl p-6 text-center hover:border-orange-500 transition-colors。

文件列表项：flex items-center justify-between p-2 hover:bg-slate-800 rounded-lg group，右侧显示文件大小，悬停时显示删除按钮。

“重建索引”按钮改为次要按钮样式：bg-slate-700 hover:bg-slate-600 text-sm rounded-lg w-full。

新增部门分组：每个部门作为一个可折叠分组（Accordion），显示部门名称、文档数量、展开/收起箭头。

5. 主聊天区改造
5.1 顶部标题栏
高度 h-16，border-b border-slate-200，bg-white/80 backdrop-blur-sm（毛玻璃效果）。

左侧显示当前对话标题“知识库问答”，右侧显示“清空对话”和“设置”图标按钮（Lucide 的 Trash2 和 Settings）。

5.2 消息气泡
AI 消息：

布局：左对齐，带头像（bg-orange-100 text-orange-600 rounded-full p-2，内放 Bot 图标）。

气泡：bg-white border border-slate-200 rounded-2xl rounded-tl-sm p-4 shadow-sm max-w-[85%]。

Markdown 渲染：使用 react-markdown + remark-gfm，表格、列表、加粗等样式需自定义。

代码块：使用 react-syntax-highlighter，深色主题，右上角增加“复制”按钮。

用户消息：

布局：右对齐，无头像或右侧头像。

气泡：bg-indigo-600 text-white rounded-2xl rounded-tr-sm p-4 max-w-[85%]。

流式打字效果：

当 AI 正在生成时，在消息末尾显示一个闪烁的光标：<span className="inline-block w-2 h-4 bg-orange-500 animate-pulse ml-1" />。

使用 Framer Motion 的 motion.div 让消息淡入：initial={{ opacity: 0, y: 10 }} animate={{ opacity: 1, y: 0 }}。

新增路由标签：在引用来源上方显示 已检索：财务部、人事部，使用 bg-blue-50 text-blue-600 text-xs px-2 py-1 rounded-full。

5.4 输入框区
悬浮在底部：sticky bottom-0 bg-gradient-to-t from-slate-50 via-slate-50 to-transparent pt-4 pb-6。

输入框容器：max-w-3xl mx-auto，bg-white border border-slate-300 rounded-2xl shadow-lg focus-within:ring-2 focus-within:ring-orange-500 transition-all。

Textarea：resize-none border-0 focus:ring-0 p-4，支持 Shift+Enter 换行，Enter 发送。

底部工具栏：左侧显示字符计数 0/4000，右侧显示发送按钮（Send 图标，bg-orange-500 hover:bg-orange-600 rounded-xl p-2 disabled:opacity-50）。

增加停止生成按钮：当 AI 正在流式输出时，发送按钮变为“停止”（Square 图标，红色背景）。

9. 注意事项
保留现有功能：改造仅涉及视觉与交互层，不得改变 API Key 透传逻辑、SSE 解析逻辑和知识库上传流程。

样式隔离：使用 Tailwind 原子类，避免全局 CSS 污染。如需自定义样式，统一放在 src/styles/globals.css。

性能优化：聊天记录超过 100 条时，考虑虚拟滚动（react-window）以避免卡顿。

暗色模式（可选）：如果时间允许，可使用 Tailwind 的 dark: 前缀支持暗色模式，通过 class="dark" 切换。

图标一致性：统一使用 Lucide React 图标库，避免混用多个图标库导致风格不一致。

字体：推荐使用 Inter 或 Geist 字体，通过 next/font 或 @fontsource 引入，提升现代感。
