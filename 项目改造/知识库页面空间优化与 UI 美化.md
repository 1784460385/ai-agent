1. 问题诊断与改造目标
现状痛点：

横向空间浪费：主内容区宽度受限，左右留白过多。

纵向堆叠低效：文件夹列表单列排列，缺乏视觉层次。

上传区孤立：拖拽上传区悬空在中间，未与目标文件夹产生强关联。

交互反馈弱：文件夹卡片缺乏悬停操作（如重命名、删除），空状态（如 Test 文件夹 0 个文件）缺乏引导。

改造目标：

将布局从“单列居中”改为“左右分栏（主从视图）”或“宽屏网格布局”，充分利用横向空间。

优化深色主题下的视觉层次（边框、阴影、状态色）。

增强交互反馈与空状态引导。

2. 核心改造：布局重构（推荐方案）
强烈建议采用 “左侧导航 + 右侧详情”的主从视图（Master-Detail），这是现代知识库/管理后台的标准范式。

2.2 AI 实现指令
将知识库页面（/knowledge 路由）拆分为两个主要区域：

左侧固定宽度侧边栏（w-72 或 w-80）：展示文件夹列表、新建按钮、搜索框、全局重建索引按钮。

右侧自适应主区域（flex-1）：展示当前选中文件夹的详细信息（文件列表、上传区、文件夹级操作）。

移除原先的 max-w-3xl 或 max-w-4xl 限制，改为 w-full max-w-7xl mx-auto px-6，充分撑满屏幕宽度。

文件夹列表项增加“选中态”（bg-slate-800 border-l-2 border-orange-500），点击后右侧主区域切换内容。

3. 视觉美化细节（深色主题）
3.1 文件夹列表（左侧导航）
卡片样式：使用 rounded-lg p-3 hover:bg-slate-800 transition-colors cursor-pointer flex items-center justify-between group。

图标：使用 Folder 图标，选中时图标颜色变为 text-orange-500。

悬停操作：悬停时在右侧显示 MoreVertical 图标，点击弹出下拉菜单（重命名、删除）。

空状态：当没有任何文件夹时，显示 📁 还没有知识库目录，点击上方新建。

3.2 上传区（右侧详情区顶部）
不要让它悬空。将其放入一个 bg-slate-800/50 border border-slate-700 rounded-xl p-6 的容器中。

使用 border-2 border-dashed border-slate-600 hover:border-orange-500 的虚线框，尺寸更紧凑（h-32 而非占满屏幕）。

上传目标直接跟随当前选中的文件夹，无需再单独放一个“导入到”下拉框（减少认知负担）。若未选中文件夹，则提示“请先在左侧选择或新建文件夹”。

3.3 文件列表与文件夹卡片
列表项：flex items-center justify-between p-3 hover:bg-slate-800 rounded-lg。

文件图标：根据文件类型显示不同颜色（PDF 红色、Word 蓝色、Excel 绿色）。

操作按钮：悬停时显示“重新索引”和“删除”按钮，避免界面杂乱。

空状态引导：如果文件夹是空的（如 Test），右侧显示：“此文件夹还没有文件，拖拽文件到上方区域开始导入吧。”

3.4 色彩与边框优化
当前背景偏黑，建议将主背景改为 bg-slate-950，卡片使用 bg-slate-900 border border-slate-800，让层次更分明。

强调色（橙色）仅用于关键操作（新建、选中态、主要按钮），避免滥用。

文字层级：标题 text-slate-100 font-semibold，副标题 text-slate-400 text-sm，标签 text-xs text-slate-500。

5. 补充功能建议（提升空间利用率与体验）
文件夹搜索：左侧导航顶部加一个搜索框（Search 图标），支持按名称过滤文件夹。

文件拖拽移动：支持将文件从当前文件夹拖拽到左侧另一个文件夹，实现快速归类。

文件预览：点击文件名，右侧弹出抽屉（Drawer）预览文件内容（PDF 可直接渲染，文本类显示前 500 字）。

索引状态标签：每个文件夹显示 已索引 / 未索引 / 索引中 状态徽章，颜色分别为绿、灰、黄。

批量操作：支持多选文件，批量删除或批量重新索引。

6. 验收标准

上传交互	拖拽文件到上传区，文件自动归入当前选中文件夹
空状态	Test 文件夹显示友好的引导文案与图标
视觉层次	深色主题下卡片、边框、文字层级清晰，无刺眼对比
动效流畅	切换、悬停、加载均有过渡动画，无卡顿
7. 注意事项
保留核心功能：改造仅涉及布局与视觉，不得改变原有 API 调用、上传逻辑和索引流程。

状态管理：当前选中的文件夹 ID 需提升到页面级状态（如 useState 或 Zustand），确保左右两侧联动。

响应式断点：建议 lg（1024px）以上使用左右分栏，以下改为上下堆叠或抽屉式导航。

性能：文件列表超过 50 项时，考虑使用虚拟滚动（react-window）。

无障碍：所有交互元素需有 aria-label，键盘可导航。
