### 关键决策
- **不在这次改写全部业务 db() 调用** — `database.py` 仍保留 `with db() as conn:` 裸 sqlite3 路径,与 SQLAlchemy 共用同一 SQLite 文件(WAL 模式);`db_lock.db_locks` 提供按表名分组的细粒度锁,新代码应当用
- **`_load_state` 用 detached 替代 expunge** — `expunge` + 关闭 session 后属性延迟访问会抛 `DetachedInstanceError`;改成在 with 块内构造新的 `ChatHistory(...)` 直接拷贝字段,消除这种潜在崩溃
- **history_router 改 db_session() 而保留 ORM 路径** — 因为 `save_chat_history` 等都通过 SQLAlchemy session 跑,共享 ORM 路径让人一眼看清楚"对话历史走 ORM,文档/文件夹走裸 sqlite3"
- **`SSEClient` 仍沿用 eventsource-parser** —— 不重新发明 SSE 解析,只把超时 / abort / 错误包装这种"工程化能力"补齐;`idleTimeoutMs` 默认 90s,聊天场景下 chat 调用单独设 180s
- **401 不在 axios 拦截器里跳转** —— 改为 dispatchEvent,React Router 决定是否 navigate;这样登录失败(已经在 /login)不会被半路打断,而且组件可以挂 toast 再离开页面
- **`apply_env()` 在 config 模块顶层运行一次** —— 任何 `import config` 之后所有常量都拿到安全默认值,无须业务代码记得调
